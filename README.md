# dmit.io：从 Pro、Eyeball、Tier 1 三条线路看懂全部套餐，新手也能一次挑对不踩坑

直接搜 `dmit.io` 的人，动机通常有三种：想确认这到底是不是那家做 CN2 GIA 的商家官网、想知道它凭什么比普通美国 VPS 贵好几倍、以及打开菜单看到几十个套餐名之后想知道自己该点哪一个。第三种最多。

这篇文章按这个顺序来：先把 `dmit.io` 背后是谁、卖什么说清楚，再把三条线路的差别摊开，然后是现在能查到的套餐和价格表，最后是优惠码、超流量规则和几个容易被忽略的坑。价格部分全部标注了来源时间和不确定性，因为 DMIT 的库存和平台换代很频繁，你今天看到的价格未必和三个月前一样。

## 先确认身份：dmit.io 卖的是什么

DMIT 是一家注册在美国的 VPS 服务商，业务从 2017 年前后开始（不同资料对注册年份的说法在 2017 和 2018 之间，但产品线本身从 2017 年就在跑）。它做的事情不复杂：在洛杉矶、香港、东京三个机房卖 KVM 虚拟化的 VPS，全系用 AMD EPYC 处理器加企业级 SSD，然后按网络线路分成不同价位的产品线。

它不像那些一个月两三美元的商家走量。DMIT 的定价逻辑基本围绕一件事：你买的不是 CPU 和内存，是回中国大陆的路由。

圈内长期流传一个说法，说搬瓦工的 CN2 GIA 带宽是从 DMIT 采购的。这个说法在多个测评站和论坛里都出现过，恒讯科技那篇分析里提到来源是 HostHum 的测评。我没办法独立验证采购关系，但 CN2 GIA 这种资源本身稀缺、上游玩家就那几家，这类说法不是空穴来风。对普通用户来说，知道这一点意味着 DMIT 在带宽资源上有一定话语权，而不是纯转卖。

付款方式对国内用户比较友好：支付宝、微信支付、PayPal、信用卡都能用，这几项在多个第三方整理里反复出现。如果你习惯用支付宝付款，不用先折腾一张外币卡。

## Pro、Eyeball、Tier 1：贵和便宜差在路由上

DMIT 最容易劝退新手的地方，就是同一个机房同一个配置，价格能差好几倍。原因全在回程线路。

| 产品线 | 回程线路 | 特点 | 适合谁 |
| --- | --- | --- | --- |
| Premium（.Pro） | 三网回程 CN2 GIA（AS4809） | 延迟最低、晚高峰最稳，价格最贵 | 电信用户为主、对稳定性敏感的建站和跨境业务 |
| Eyeball（.EB） | 三网回程 CMIN2，电信/联通另有 AS9929 | 同价位给的流量和带宽更多，线路次一档 | 移动、联通用户，或者流量吃得多、预算有限的场景 |
| Tier 1（.T1） | 国际 BGP，无中国大陆专项优化 | 便宜、带宽大、流量多，回国速度不保证 | 面向海外用户的业务、中转、备份、只想要个美国 IP |

理解这张表之后，选套餐的逻辑就简单了：先确定你主要服务的用户在国内还是国外，再看自己的宽带运营商，最后才是比 CPU 和内存。

有个细节值得单独说。香港的 Tier 1 产品线没有大陆优化，有测评站直接提醒电信用户不要买错，因为可能出现香港节点延迟比美国还高的情况。这不是商家的问题，是线路性质决定的：便宜就便宜在没有回国优化上。

## 香港和东京：什么时候值得多花钱

**香港**是 DMIT 最贵的机房，也是回国延迟最低的。第三方测评给出的香港 Premium 三网平均 Ping 大约在 40ms 出头，电信、联通、移动都在 42–46ms 区间；香港 Tier 1 则要便宜不少，入门款年付 $36.9 起，1 核 1G / 20G / 1T 月流量，但它走国际 BGP，不保证大陆速度。

香港 Premium 的价格量级参考：TINY 1 核 1G / 20G / 1Gbps / 400–500G 月流量，$39.9/月；再往上 STARTER 大约 $79.9/月，配置更高的档位价格依次到 $500/月。不同平台（AS3 与 AN5）和不同时期的配置、流量数字在多个来源之间有出入，具体数字请以结账页为准。

**东京**的位置介于两者之间。TYO.Pro（CN2 GIA 回程）入门款月付 $21.9 起，1 核 1G / 20G / 500G 月流量；TYO.EB 月付 $25.9 起，走日本三网 CMI 回程；TYO.T1 则是最低 $36.9/年那一档。如果业务对延迟很敏感——比如实时接口、跨境电商后台——东京比洛杉矶值得考虑，比香港便宜。

需要注意一点：香港的 Eyeball 系列有资料显示已经下线，目前香港主要提供 Premium 和 Tier 1。DMIT 的产品线调整比较频繁，点进去之前不要默认某个系列一定在售。

## 优惠码：能用，但限制很多

DMIT 的优惠码不像一般商家那样一张通用码走天下。它按产品线、付款周期分别授权，填错就是验证不通过。使用方式倒简单：在结账页选好套餐和周期，填码后点 Validate Code。

目前在多个整理中反复出现、被标注为长期有效的主要是这两张：

- `Lite-Annually-Recur-30OFF`：年付 7 折循环优惠，适用 Standard（原 Lite）网络系列
- `Lite-Semi-Annually-Recur-20OFF`：半年付 8 折循环优惠，同系列

另外还有针对特定线路的循环码，比如洛杉矶 EB 系列非月付的 8 折码、香港/东京 Pro 季付及以上的 8 折码，以及香港 EB 年付的 85 折码。这类码的可用性随活动变化，我没办法在这里保证任何一张当前仍然有效。

> 一个实用原则：优惠码只在结账页验证通过的那一刻才算数。第三方文章里写的码，包括上面这两张，都可能在你看到的时候已经过期或者改了适用范围。

## 超流量、换 IP 和几个容易忽略的点

流量用超了会怎样，这是很多人下单前最关心的事。DMIT 的做法是限速不停机：超过标定的月流量之后，端口降到 4–10Mbps（Tier 1 最高能保留到 100–500Mbps），但不切断服务、不额外扣费。对建站来说这个设计比直接停机友好得多——站点会变慢，不会挂掉。

换 IP 这块，网上流传的说法是每 15 天可以免费换一次，超出后 $5/次。不过论坛里也有用户提到，部分产品线已经改成提交工单换 IP，流程不再是后台点一下。这两件事可能同时成立（不同产品线规则不同），也可以都是阶段性调整，下单前值得自己确认一下。另外要说清楚：DMIT 是线路机，从来不承诺 IP 的“纯净度”。有用户反馈过 IP 质量评分下滑的问题——原因通常是同网段有人跑攻击或滥用，不是商家主动为之。如果你对 IP 信誉有硬需求，常规做法是套一层小众机房或者家宽做落地。

再有就是维护通知。有分析指出 DMIT 升级宿主机时通常不提前发邮件，用户可能突然发现机器短暂不可用。如果你的业务对可预期性要求很高，这一点要提前有心理准备。

选购之前，建议先用官方的 looking glass 测一下本地到目标机房的实际路由，地址是 `lg.dmit.sh`，洛杉矶 Pro、洛杉矶 EB、东京 Pro 各有独立入口。花五分钟测一遍，比看十篇评测都准。

## 那到底该买哪个

如果你的用户主要在国内、你用的是电信宽带：洛杉矶 Pro 的 TINY 或 Pocket 起步，12.98 美元一个月不算便宜，但这是 CN2 GIA 三网回程里门槛较低的一档。轻量博客、个人站、小工具服务，1 核 2G 够用。

如果你是移动或联通用户，或者流量吃得多：直接看 Eyeball。同价位多出一倍的流量和带宽，实际体验差距没有价差那么大。

如果你的用户在国外，或者你只是要一台美国机器做中转、备份、跑脚本：Tier 1。$36.9/年那一档经常缺货，有货就别犹豫，它的定位本来就是价格洼地。

如果你的业务对延迟极其敏感、预算也够：香港 Premium，接受 40ms 级别的延迟和明显更高的月费。
